# Fingerprint Lab

Independent browser fingerprinting and tracking research laboratory.

**Live laboratory:** https://fingerprint-lab.pages.dev/

## What you can explore

- **Fingerprint Pro** — compare direct and first-party identification methods, examine test results, and export your own observations.
- **Server Lab** — optionally inspect additional information associated with a test, subject to access authorization and service availability.
- **First-party Tracking Simulator** — explore how browser storage and behavioral events can be used in a local demonstration.
- **FingerprintJS OSS** — examine browser fingerprint components and export raw test results.
- **Section analytics** — optional, consent-based insights into how visitors interact with different parts of the laboratory.
- **Privacy information** — review how the laboratory uses external services and handles test data.

## Using the laboratory

Open the live laboratory, select a test, and follow its on-screen instructions. Identification tests run only when explicitly initiated. Some optional features require authorized access.

Results depend on the browser, configuration, network, and available service capabilities. Repeated tests can help assess whether visits are linked; a single result does not establish anonymity or reliable identification.

## Privacy

Google Analytics 4 is optional and requires separate consent. Section analytics measure interactions with the laboratory; they do not include Fingerprint visitor IDs, event IDs, access tokens, or raw test results.

The tracking simulator's demonstration data stays in the browser. Cloudflare provides hosting and traffic analytics.

For further details, read the **Privacy and Data Processing** information on the website.

## Purpose and attribution

Fingerprint Lab is an independent research and testing project, **not a production anti-fraud service**.

It uses Fingerprint Pro and FingerprintJS OSS for testing and comparison. It is **not affiliated with or endorsed by Fingerprint**.
