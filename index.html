Fingerprint Lab

Kontrolirano testiranje ponovne identifikacije preglednika kroz sesije, kontejnere i mrežne promjene. Fingerprint Pro Agent v4, EU regija: usporedi izravni pristup i Cloudflare first-party proxy na istoj stranici. Identifikacija se pokreće isključivo ručno.

01 / Pokretanje testa

Agent: Fingerprint v4 · Regija: eu

Direktno učitavanje agenta preko Fingerprint CDN-a.

Zahtjev šalje podatke usluzi Fingerprint i može biti vidljiv vlasniku testnog workspacea. GA4 je opcionalan i učitava se tek nakon zasebne privole. Cloudflare Web Analytics i serverski middleware mogu bilježiti statistiku prometa. VID i rezultat identifikacije prikazani su samo tijekom ove sesije stranice.

GA4: isključen (bez privole).

Kod oba načina SDK se učitava tek nakon pritiska gumba. Proxy način zahtijeva Cloudflare Pages; blokiranje direktnog načina također je rezultat testa.
