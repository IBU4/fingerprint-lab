Privatnost i obrada podataka

Fingerprint Lab javni je, neovisni istraživački laboratorij. Ovdje je opisano kako rade testovi, lokalna pohrana i povezane usluge.

Otvaranje stranice

Cloudflare Pages poslužuje web-stranicu i tehnički obrađuje HTTP zahtjeve. Cloudflare Analytics Engine middleware, ako je konfiguriran, bilježi putanju zahtjeva (za proxy sažetu na /bridge), HTTP metodu, status odgovora, državu, ASN, približnu kategoriju preglednika, Sec-Fetch-Mode i trajanje zahtjeva. Objavljeni middleware ne upisuje IP adresu, Visitor ID ili sadržaj zahtjeva u taj skup podataka. Cloudflare infrastruktura može zasebno obrađivati tehničke podatke o prometu. Cloudflare Web Analytics zasebno bilježi statistiku posjeta neovisno o dobrovoljnim testovima.

Fingerprint Pro — dobrovoljni test

Agent Fingerprint Pro učitava se tek nakon označavanja potvrde i pritiska gumba za pokretanje identifikacije. Način Direct šalje zahtjeve izravno servisu Fingerprint; 1P Proxy usmjerava ih preko Cloudflare Pages Function prema servisu Fingerprint (EU regija). Servis može obrađivati signale uređaja i preglednika, mrežne podatke i rezultate identifikacije prema svojim pravilima. Rezultat i povijest testa u sučelju ostaju u memoriji kartice; korisnik ih može sam kopirati ili izvesti u JSON. Obrada kod pružatelja usluge odvojena je od lokalnog prikaza.

Server Lab — zaseban dohvat postojećeg događaja

Sekcija 03 koristi neovisnu Cloudflare funkciju za ručni dohvat postojećeg Fingerprint Server API događaja. Ne učitava dodatni Fingerprint Agent niti pokreće novo mjerenje. Dohvat zahtijeva privatni pristupni token laboratorija, a Fingerprint Secret API Key čuva se kao Cloudflare Secret i nikada se ne šalje pregledniku. Pristupni token se ne sprema u kolačić ni localStorage; prosljeđuje se samo Cloudflare funkciji tijekom autoriziranog HTTPS zahtjeva. Serverski rezultat može uključivati IP adresu, mrežne podatke, identifikacijske signale i druge podatke dostupne unutar plana. JSON se prikazuje u trenutnoj kartici i može se ručno kopirati ili spremiti; laboratorij ga ne sprema u vlastitu bazu. Cloudflareova infrastruktura i postojeći middleware i dalje mogu bilježiti tehničke metapodatke HTTP zahtjeva.

Google Analytics 4 — zasebna privola

GA4 skripta učitava se tek nakon zasebne označene privole. Stranica inicijalizira GA4, omogućuje analitičku pohranu i šalje standardni page_view; oglasna pohrana i personalizacijski signali postavljeni su na denied. Povlačenje privole postavlja analitičku pohranu na denied i pokušava ukloniti lokalne GA kolačiće. Već učitanu skriptu nije moguće potpuno ukloniti bez osvježavanja stranice. Uz privolu se na početnoj stranici mogu slati događaji section_view, section_engagement i section_interaction: oznaka sekcije, približno aktivno trajanje njezine vidljivosti, odabrane radnje te, samo ako je izričito zadan URL parametar, oznaka simuliranog scenarija. To nije mjerenje čitanja ili stvarne pozornosti, nego vidljivosti dijela stranice dok je kartica aktivna. Ova analitika ne šalje Visitor ID, Event ID, pristupni token ili sadržaj rezultata i JSON-a. Događaji se ne stvaraju prije GA4 privole i prestaju se slati nakon povlačenja privole. Dijagnostika i oznaka sumnje na adblocking nisu dokaz da je događaj zaprimljen ili blokiran.

1P Custom Tracking Simulator

Simulator koristi lokalno posluženu FingerprintJS OSS biblioteku. Demonstracijski profil i događaji ostaju u memoriji kartice i ne šalju se kao analitički događaji na poslužitelj. Simulator sprema demonstracijski Tracking ID u localStorage i kolačić s trajanjem do 30 dana; tipka za resetiranje identiteta služi uklanjanju tog identiteta. Nakon ručnog pokretanja postoji i zasebna provjera uspješnosti 1P komunikacije: poslužitelj postavlja nasumični sesijski kolačić (bez roka trajanja), a Cloudflare D1 bilježi isključivo pripadni nasumični ključ pokušaja i logičku vrijednost uspjeha. Nakon očitanja vrijednost se vraća na false; zapis ostaje u bazi do administrativnog uklanjanja. U D1 se ne šalju Fingerprint ID, demonstracijski događaji niti sadržaj profila. Ta provjera nije dokaz da adblocker postoji ili ne postoji. HTTP zahtjevi za stranicu i datoteku biblioteke zasebno prolaze kroz Cloudflare infrastrukturu i middleware.

FingerprintJS OSS — sirove komponente

Na zasebnoj stranici može se ručno pokrenuti lokalno mjerenje FingerprintJS OSS bibliotekom koju poslužuje ova domena. Komponente, preglednikov kontekst i raw JSON prikazuju se u kartici; stranica ne šalje te rezultate Fingerprint Pro API-ju i ne sprema vlastite identifikatore u cookies ili localStorage. Korisnik ih može kopirati ili preuzeti. Cloudflare poslužuje stranicu i skriptu te može evidentirati njihove HTTP zahtjeve.
